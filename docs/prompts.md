| خطا | علت | رفع |

### تصمیم‌ها
Claude قبل از هر دانلودی منبع داده‌ها را جست‌وجو کرد و فقط فراداده‌ها (metadata) را از
Hugging Face خواند. دو سؤال پرسید:

| سؤال | گزینه‌ها | تصمیم من |
|---|---|---|
| کدام dataset؟ | Snappfood (حدود ۶۹٬۵۰۰ نظر، دوکلاسه)، DKSF (۳ کلاسه)، Digikala (حدود ۳ هزار نظر؛ برای ۱٪ برچسب خیلی کوچک است) | **Snappfood** |
| مجموعه‌ی آزمون؟ | ادغام و تقسیم دوباره‌ی همه‌ی داده، یا استفاده از test رسمی | **test رسمی** |

پیامد: `train.csv` و `validation.csv` با هم مجموعه‌ی آموزش را می‌سازند. `experiment.test_size`
حذف شد و بخش `data` جای آن را گرفت.

### خطاها و رفع آن‌ها

| خطا | علت | رفع |
|---|---|---|
| نگرانی درباره‌ی نصب hazm روی Python 3.12 | نسخه‌های قدیمی hazm نسخه‌ی قدیمی numpy را لازم داشتند | dry-run نصب نشان داد hazm 0.12.1 وابستگی سبکی دارد و مشکلی ندارد |
| API فراداده‌ی PNLPhub پاسخ JSON نداد | dataset به `ParsiAI/...` منتقل شده و پاسخ HTTP 307 (redirect) بود | دنبال‌کردن redirect و استفاده از آدرس جدید |
