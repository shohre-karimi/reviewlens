# دفترچه‌ی پرامپت‌ها

این فایل نقش هوش مصنوعی (Claude Code) در ساخت پروژه را شفاف ثبت می‌کند: پرامپت‌های مهم،
تصمیم‌هایی که در گفت‌وگو گرفته شد، و خطاهایی که پیش آمد و نحوه‌ی رفعشان.

## فاز ۱: اسکلت و طراحی

### پرامپت اصلی
مشخصات کامل پروژه در `CLAUDE.md` نوشته شد. پرامپت شروع:

> CLAUDE.md را کامل بخوان. اگر سؤالی درباره‌ی مشخصات داری اول بپرس، بعد فاز ۱ را شروع کن.
> بعد از هر فاز صبر کن تا تأیید کنم.

### سؤال‌های روشن‌سازی و تصمیم‌ها
Claude پیش از نوشتن کد، محیط سیستم را بررسی کرد و سه سؤال پرسید:

| مسئله | تصمیم |
|---|---|
| فقط Python 3.15 نصب بود؛ ممکن است hazm و scikit-learn برایش wheel نداشته باشند | نصب و استفاده از **Python 3.12** |
| `make` روی ویندوز نصب نبود ولی معیار پایان کار به آن وابسته است | نگه‌داشتن Makefile و نصب make با `winget install ezwinports.make` |
| پوشه repository گیت نبود | `git init` و یک commit پس از تأیید هر فاز |

### تصمیم‌های طراحی پیشنهادی Claude (تأییدشده توسط من در پایان فاز)
- وابستگی‌ها مرحله‌به‌مرحله به `pyproject.toml` اضافه می‌شوند، نه همه از ابتدا.
- تنظیمات با pydantic و `extra="forbid"`: کلید ناشناخته در YAML خطا می‌دهد.

### خطاها و رفع آن‌ها

| خطا | علت | رفع |
|---|---|---|
| `winget install ezwinports.make` با خطای `0x8a15003b : Rest API internal error` متوقف شد | winget علاوه بر منبع `winget` در منبع `msstore` هم جست‌وجو می‌کرد و آن منبع خطا داد | افزودن `--source winget` به دستور |
| بعد از نصب، `make` در همان ترمینال شناخته نمی‌شد | PATH ترمینال باز به‌روز نمی‌شود | باز کردن ترمینال جدید (یا بارگذاری دوباره‌ی PATH) |

تست‌ها (۲۹ تست)، ruff، mypy و هوک‌های pre-commit در اولین اجرا بدون خطا گذشتند.
